Найти недвижимость с самым большим количеством спален (bedrooms) и напишите ее название 


Тестовая коллекция в mongo atlas  sample_airbnb.listingsAndReviews

Найти недвижимость с самым высоким рейтингом  review_scores_rating при минимальном количестве отзывов 50 (number_of_reviews) и напишите ее название 


РЕШЕНИЯ

1. Все кинотеатры в Калифорнии:

db.getSiblingDB("sample_mflix").theaters.find({
    "location.address.state": "CA"
})

Количество кинотеатров в Калифорнии:

db.getSiblingDB("sample_mflix").theaters.countDocuments({
    "location.address.state": "CA"
})

2. Недвижимость с самым большим количеством спален:

db.getSiblingDB("sample_airbnb").listingsAndReviews.find(
    { bedrooms: { $type: "number" } },
    {
        _id: 0,
        name: 1,
        bedrooms: 1
    }
).sort({ bedrooms: -1 }).limit(1)

3. Недвижимость с самым высоким рейтингом при количестве отзывов не менее 50:

db.getSiblingDB("sample_airbnb").listingsAndReviews.find(
    {
        number_of_reviews: { $gte: 50 },
        "review_scores.review_scores_rating": { $type: "number" }
    },
    {
        _id: 0,
        name: 1,
        number_of_reviews: 1,
        "review_scores.review_scores_rating": 1
    }
).sort({ "review_scores.review_scores_rating": -1 }).limit(1)
